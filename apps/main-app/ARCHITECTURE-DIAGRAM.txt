Deterministic Execution Cycle (100Hz = 10ms):

┌─────────────────────────────────────────────────────────────────────────────┐
│                         Runtime Cycle (every 10ms)                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  1. For each service:                                                       │
│     └─ poll()                                                               │
│        ├─ Read ONE message from inbound mailbox                             │
│        ├─ Process message via handle()                                      │
│        └─ Generate ONE outbound message via generate_outbound()             │
│                                                                             │
│  2. Route all outbound messages:                                            │
│     └─ For each outbound message:                                           │
│        ├─ Determine destination(s) via Router                               │
│        └─ Deliver to destination service's inbound mailbox                  │
│                                                                             │
│  3. Sleep until next cycle (if time remaining)                              │
│                                                                             │
│  Result: ONE message processed per service per cycle                        │
│          → Deterministic, predictable execution                             │
│          → Observable message flow                                          │
│          → No race conditions                                               │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
